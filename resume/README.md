# 简历模板

用浏览器打开 `index.html`，填写灰色占位后打印为 PDF。

## 填写

将【姓名】【手机号】【邮箱】【学校】【专业】【时间】【求职意向】替换为实际信息。

含个人信息的文件请勿推送到 GitHub。本地备份可另存为 `我的简历.html`（已加入忽略规则）。

## 按岗位调整

- 开发 / 测试 / 实施：可保留当前四项，意向改为对应岗位。
- 嵌入式 / 硬件：将智能鱼缸置于首位。
- AIGC / 独立开发：将创作工作台与错题工具前移。
- 游戏 / 前端：末项替换为樱夜·尸潮。
- 市场相关岗位：减少 mAP、JWT 等实现细节，侧重解决的对象与结果。

## 导出 PDF

使用 Chrome 打开 `index.html`，打印并选择「另存为 PDF」。纸张为 A4，关闭页眉页脚。
