# 简历模板

打开 `index.html`，填灰色占位，再用浏览器打印成 PDF。

## 填写

把【姓名】【手机号】【邮箱】【学校】【专业】【时间】【求职意向】换成你的信息。

不要把填好个人信息的文件推到 GitHub。需要自己留底时，另存为 `我的简历.html`（已加入忽略规则）。

## 按岗位微调

- **开发 / 测试 / 实施**：保持现在这 4 项，意向写成对应岗位。
- **嵌入式 / 硬件**：鱼缸放最前，可再补一条工地或体育馆。
- **AIGC / 独立开发**：把工作台和错题本挪到最前。
- **游戏 / 前端**：用樱夜·尸潮替换最后一项。
- **技术型市场**：少写 mAP、JWT，多写你解决了谁的哪一步。

## 导出 PDF

1. 用 Chrome 打开 `index.html`
2. 打印，目标选「另存为 PDF」
3. 纸张 A4，边距默认，取消页眉页脚
