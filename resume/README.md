# 简历模板

打开 `index.html`，把灰色占位换成自己的，再用浏览器打成 PDF。

## 填写

改【姓名】【手机号】【邮箱】【学校】【专业】【时间】【求职意向】。

填好个人信息的文件不要推到 GitHub。自己留底就另存为 `我的简历.html`（已经忽略了）。

## 按岗位改

- 开发 / 测试 / 实施：这 4 条可以不动，意向改成对应岗位。
- 嵌入式 / 硬件：鱼缸放最前。
- 出图 / 独立开发：把工作台和错题本往前挪。
- 游戏 / 前端：最后一项换成樱夜·尸潮。
- 偏市场：少写 mAP、JWT，多写你给谁解决了什么。

## 导出 PDF

Chrome 打开 `index.html`，打印，目标选「另存为 PDF」。纸张 A4，页眉页脚关掉。
