# 体育馆系统怎么点

## 地址和账号

- 前端：`http://localhost:7000`
- 后台登录：`http://localhost:7000/login`
- 学生首页：`http://localhost:7000/front/home`
- 后端：`http://localhost:9090`
- 管理员：`admin / admin`
- 普通用户：`zhangsan / 123`
- 数据库：`sport-manage`（示例是 `root / root`，按你本机改）

## 启动

```powershell
cd projects\campus-sport
.\scripts\start-db.ps1
.\scripts\start-backend.ps1
.\scripts\start-frontend.ps1
```

后端要先打包：

```powershell
cd admin
mvn -DskipTests package
```

预约时段过期了就跑：

```powershell
.\scripts\reset-demo-data.ps1
```

可约日期会推到 7 天后。

## 学生端

1. 打开首页，看轮播、推荐场地、公告。
2. 翻一下教学视频，搜个场地，比如“田径场”。
3. 用 `zhangsan / 123` 登录，进详情，约一个还没到的时段。
4. 填姓名和电话，付钱、签到、结算、评价。
5. 在“体育器材”借一件，再到“我的器材借用”还掉，看库存有没有加回去。

## 管理端

1. `admin / admin` 进后台。
2. 看用户、场地、订单、评价、公告、教学视频、轮播图。
3. 看时段、维护、支付方式、器材库存和借用记录。
4. 打开“数据报表”。能手动刷，页面自己也会 30 秒刷一次。

## 实现上就这些

- 登录：BCrypt 对密码，JWT 发 token
- 权限：角色决定菜单和按钮；前端把 token 放 Pinia，路由登录后再挂
- 器材：借了减库存，还了加回去
- 报表接口：`GET /dashboard/summary`
