# 高校体育馆管理系统演示手册

## 地址与账号

- 前端：`http://localhost:7000`
- 后台登录：`http://localhost:7000/login`
- 用户首页：`http://localhost:7000/front/home`
- 后端接口：`http://localhost:9090`
- 管理员：`admin / admin`
- 普通用户：`zhangsan / 123`
- 数据库：`sport-manage`（默认 `root / root`，按本机修改）

## 启动

```powershell
cd projects\campus-sport
.\scripts\start-db.ps1
.\scripts\start-backend.ps1
.\scripts\start-frontend.ps1
```

后端需先打包：

```powershell
cd admin
mvn -DskipTests package
```

若预约时段已过期，执行：

```powershell
.\scripts\reset-demo-data.ps1
```

脚本会把可预约日期推到 7 天后。

## 用户端

1. 打开首页，查看轮播、推荐场地、公告。
2. 查看运动教学和场地搜索（例如“田径场”）。
3. 用 `zhangsan / 123` 登录，进入场地详情并预约未来时段。
4. 填写姓名、电话，完成支付、签到、结算、评价。
5. 在“体育器材”申请借用，再到“我的器材借用”归还，确认库存回升。

## 管理端

1. 用 `admin / admin` 登录后台。
2. 检查用户、场地、预约订单、评价、公告、教学视频、轮播图。
3. 检查时段、场地维护、支付方式、器材库存和借用记录。
4. 打开“数据报表”，确认统计卡片、状态分布、热度图和最近订单；可手动刷新，页面也会每 30 秒更新。

## 技术要点

- 登录：BCrypt 校验密码，Sa-Token / JWT 签发 token
- 权限：角色菜单与按钮权限，前端 Pinia 保存 token / menus / auths，动态挂载路由
- 器材：借用扣库存，归还回库存
- 报表：`GET /dashboard/summary`
