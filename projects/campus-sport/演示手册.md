# 演示手册

## 地址与账号

- 前端：`http://localhost:7000`
- 管理端登录：`http://localhost:7000/login`
- 用户首页：`http://localhost:7000/front/home`
- 后端：`http://localhost:9090`
- 管理员：`admin / admin`
- 普通用户：`zhangsan / 123`
- 数据库：`sport-manage`（示例账号 `root / root`，请按本机修改）

## 启动

```powershell
cd projects\campus-sport
.\scripts\start-db.ps1
.\scripts\start-backend.ps1
.\scripts\start-frontend.ps1
```

后端需先打包：

```powershell
cd admin
mvn -DskipTests package
```

若预约时段已过期，执行：

```powershell
.\scripts\reset-demo-data.ps1
```

可预约日期将顺延 7 天。

## 用户端

1. 打开首页，查看轮播、推荐场地与公告。
2. 浏览教学视频，并检索场地（例如“田径场”）。
3. 使用 `zhangsan / 123` 登录，进入场地详情并预约未开始的时段。
4. 填写姓名与电话，完成支付、签到、结算与评价。
5. 在“体育器材”申请借用，于“我的器材借用”归还，确认库存已恢复。

## 管理端

1. 使用 `admin / admin` 登录。
2. 查看用户、场地、订单、评价、公告、教学视频与轮播图。
3. 查看时段、维护计划、支付方式、器材库存与借用记录。
4. 打开“数据报表”。支持手动刷新，页面亦每 30 秒自动更新。

## 实现要点

- 登录：BCrypt 校验密码，JWT 签发 token
- 权限：按角色分配菜单与按钮；前端以 Pinia 保存 token，路由在登录后注册
- 器材：借用扣减库存，归还后恢复
- 报表接口：`GET /dashboard/summary`
